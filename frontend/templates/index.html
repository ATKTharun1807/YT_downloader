About

Tech Stack
  • 🐍 Python + Flask
  • 📥 yt-dlp (download engine)
  • 🎬 FFmpeg (stream merging)
  • 🌐 HTML / CSS / JavaScript
  • 🔴 Server-Sent Events (live progress)
Features
  • ✅ 4K / 2K / 1080p / 720p / 480p
  • ✅ MP3 Audio Extraction
  • ✅ Playlist Support
  • ✅ Real-time Progress
  • ✅ Download History
  • ✅ Secure URL Validation
Security

This application validates all URLs against a YouTube domain whitelist before processing. Filesystem paths are checked against allowed download directories to prevent path traversal. No shell commands are executed with user input. Rate limiting protects against abuse. All errors are logged server-side; no stack traces are shown to users.

⚠ Use this application only for content you are authorized to download and in accordance with YouTube's terms and applicable copyright laws. This tool does not bypass DRM, authentication, or access restrictions.
